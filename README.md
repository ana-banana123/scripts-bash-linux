# 🐧 Scripts Bash para Linux

Coleção de scripts desenvolvidos durante meus estudos de Linux e programação em Bash.

Este repositório reúne diferentes scripts desenvolvidos para praticar automação de tarefas, gerenciamento de arquivos, processos, usuários e informações do sistema.

## 🛠️ Tecnologias

- Bash
- Linux
- Shell Script

## 📚 Conteúdos praticados

- Variáveis
- Entrada de dados
- Estruturas condicionais
- Estruturas de repetição
- Manipulação de arquivos
- Gerenciamento de processos
- Permissões de arquivos
- Informações do sistema
- Gerenciamento de usuários
- Automação de tarefas

## 🔎 Comandos e ferramentas utilizados

- `grep`
- `find`
- `whereis`
- `locate`
- `chmod`
- `ps`
- `wc`
- `uname`
- `mv`
- `rm`

## 🎯 Objetivo

Praticar programação em Bash e desenvolver familiaridade com o ambiente Linux, automação de tarefas e administração básica do sistema.
